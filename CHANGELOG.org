** [0.1.3] - 2026-10-21
*** Feature:
             - Dynamic grid size:
               - clj-baduk.engine, clj-baduk.board, clj-baduk.utilities, dev
		 namespaces now supports a configurable grid size, set in
		 'config.clj'.
               - The grid sizes are invariants of either 9x9, 13x13 or 19x19
               - (All tests are updated to support grid-size)
               - utilities.terminal-board major refactoring
             - Dev and user namespaces are properly functional, with proper
	       tooling for interaction between Graphics board game state and
	       REPL.
	     - Improved domain semantics:
	       - baduk for the game name as opposed to 'Go' which appeared way to
		 comp-sci generic (the programming language).
	       - the 'go-string' is refactored to 'chain', as the previous name
		 was problematic for several reasons.
*** Changed:
             - Upgrade to Clojure 1.12.6
             - clj-go.board minor refactorings.
	     - MAJOR RENAME: GitHub repo, build and deps, all namespaces, all
	       function names, all vars and let bindings are renamed:
	       - clj-go ---> clj-baduk, go --> baduk, Go --> Baduk
	       - go-string --> chain
*** Fixed:
             - Broken changelog

*** Removed:
